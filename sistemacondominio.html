🏢 Sistema de Gestão de Condomínio

Desenvolvi um sistema full stack para gerenciamento de condomínios, com autenticação de usuários, controle de acesso por perfil (Administrador e Porteiro) e dashboard interativo. O sistema permite o gerenciamento de moradores, visitantes, ocorrências, porteiros e usuários, com interface moderna e responsiva.

🔧 Tecnologias utilizadas

  • 🟢 Node.js
  • ⚡Express
  • 🐬 MySQL
  • 📄HTML5
  • 🎨CSS3
  • 📜JavaScript
  • 🔒bcrypt
  • 📊Chart.js

🚀 Funcionalidades principais

  • ✅ Login seguro com autenticação e criptografia de senhas
  • ✅ Controle de permissões por perfil (Admin/Porteiro)
  • ✅ CRUD completo de moradores, visitantes, usuários e ocorrências
  • ✅ Dashboard com estatísticas e gráficos
  • ✅ Interface responsiva e organizada
  • ✅ API RESTful integrada ao frontend
